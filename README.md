Sales and Profit Analysis Dashboard
 Project Overview
This project presents an interactive Sales and Profit Analysis Dashboard built in Microsoft Excel. The dashboard helps analyze sales performance, profitability, product performance, department-wise trends, and location-based insights using Pivot Tables, Pivot Charts, KPI Cards, and Data Visualization techniques.
---
 Objectives

Analyze total sales and profit performance.

Identify top-performing departments and products.

Track monthly sales trends.

Compare sales and profit across different locations.

Provide business insights through interactive visualizations.



---

 Key Performance Indicators (KPIs)
