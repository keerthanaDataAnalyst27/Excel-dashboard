# Excel-dashboard
Excel dashboard
Data Analyst Project – Sales Data Analysis Dashboard
Project Overview
This project focuses on analyzing sales data using Microsoft Excel. The objective is to clean, process, visualize, and create an interactive dashboard that provides meaningful business insights from sales transactions.
The project demonstrates essential Data Analyst skills, including:
Data Cleaning
Data Processing
Data Visualization
Dashboard Creation
Business Insights Generation
 Project Objectives
Analyze sales performance across different departments.
Identify top-performing products.
Evaluate profit and cost trends.
Compare sales across locations.
Create an interactive dashboard for decision-making.
